Moth 50 is the working name for the next model in the family, and it is not
published yet. 0.8.1 had to fit in 20 MB; it uses 19,706,289 bytes. The next
model is a separate project, built to a ceiling under 50 MB.

The extra room is for capacity the current package cannot afford, not for a
different task or a server-side deployment. There are no weights, no demo and
no numbers yet; nothing on this page is a result.
